[h2]Stock and Base Ledger[/h2]
Set shared room/building item targets in the normal menu; read Current / Target / Remaining on paper or PC. The PC app alerts on complete live shortages. Connect computers in PC Network and view the newest local ledger copy for each building. Each remote building needs a loaded, powered, authorized PC with its own ledger CD. No unloaded-world live data.

B47ANCE'd Quartermaster helps you organize storage, put supplies away and keep track of what you need.

Tell each container what belongs inside, then sort your inventory, a room or an entire building from one menu.

[h2]Sorting made simple[/h2]
• Choose whole categories or individual items in a searchable tree with native item icons.
• Configure several containers in one window. Save keeps the editor open so you can select the next container. Give sections their own rules or share settings across a Whole Container.
• Save and reuse sorting presets, copy settings between containers and set destination priorities.
• Sort your carried inventory, a selected container, the current room or the entire building. Room and building sorting include your carried bags.
• Sort supported floor, Proximity Inventory, selected vehicle/trailer cargo and nested carried-bag sources into configured storage. Native access and capacity checks still apply.
• Find what you need with category/item search, Only Checked, Only Contents and optional grouping by mod.
• Make quick changes with Shift-click ranges, Ctrl-click, Select All Visible, Clear All Visible and Invert Visible.

Open Quartermaster from your player inventory. Select categories to include them, expand them to choose individual items, then save your container's rules.

[h2]Shopping lists[/h2]
Create a named shopping paper from one blank sheet using a retained notebook and pen or pencil. Choose among the lists you carry, give them to friends before a loot run, or hold one in either hand for a small paper checklist HUD. Writing supplies are needed for creating/editing; reading and collecting do not need them. Previous personal plans are preserved for explicit one-time import.
• Add items manually or from supported crafting, building and cooking recipes.
• Set quantities and see what you carry and what is still missing.
• Collect remaining items from eligible nearby storage.
• Choose acceptable condition, food state and remaining uses, with preferences for individual items.

[h2]Building Supply Ledger[/h2]
Sort uses a carried Supply Sheet and pen/pencil by default. It first searches accessible loaded building storage for a completed covering ledger and picks it up normally, otherwise using a carried blank/unfinished sheet. One writing action records confirmed touched storage after the whole successful Sort; blank sheets stay partial and unvisited entries keep their timestamps. Disable SortUpdatesLedger to restore the earlier workflow. Shopping collection requires fresh covering knowledge from completed paper or a matching CD at an authorized powered computer. Planning, reading and container configuration need no supply ledger. Physical-list edits need writing supplies. Server settings can disable ledger requirements.
Computers open a Windows '93 desktop. Find a Quartermaster Application CD, load it through CD-ROM (D:) and run SETUP.EXE to install the app on each PC. The setup disc is reusable and need not stay nearby afterward. Use CD Writer to create a ledger CD, then load that disc and run QUARTERMASTER.EXE to view it.
Craft a Supply Sheet by consuming one whole notebook while retaining the clipboard and pen/pencil, then walk through building or safehouse storage to record what is there, including unconfigured containers. Paper pages show rooms, containers, quantities, locations and recording times. Interrupted inspections keep completed entries.

Copy a completed paper sheet onto a chosen vanilla CD at a powered desktop. Paper stays intact; the CD's music is overwritten. Search items and browse locations in the app. Server modes offer periodic live statistics, no-expiry statistics or historical snapshots; Disabled turns off ledgers/CDs/computers. Freshness defaults to 7 in-game days. Computers refresh automatically only in the exact recorded building unless manual inspection/CD updates are required. Off-site/safehouse-wide CDs retain historical access. Live data covers recorded, loaded storage; new storage needs inspection.

[h2]Rooms and your base[/h2]
Use [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3820077442]B47ANCE'd Rooms[/url] to designate rooms and organize storage around your base. Open Designate Room from Quartermaster, then choose room or building sorting when putting supplies away.

Quartermaster checks container and room access when sorting. Room policies apply to supported mod actions; they do not lock ordinary game interactions.

For automated cleaning, add the separate [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3820151540]B47ANCE'd Auto Clean[/url] mod.

[h2]Make it yours[/h2]
Resize the window, adjust the container divider and set background transparency. Mouse, keyboard and controller controls are included. Server sandbox settings control discovery range, area sorting, ledger requirements, physical lists, writing supplies and carrying allowance. Dangerous Load is optional and disabled by default; native capacity limits and encumbrance still apply.

[h2]Current limits[/h2]
Native client/dedicated acceptance is pending. Real ledger CDs stay in accessible storage beside the PC. Expired pages remain readable history. Selected vehicle/trailer sources work; automatic parked-vehicle area sweeps, vehicle destinations, fluid tanks and unverified virtual storage are unsupported. Cooking plans support full portions, not partial portions or fluids. Room policies do not lock unrelated vanilla transfers.

Room organization uses designated B47ANCEDRooms rooms only; native buildings define building scope. Allocation limits and live role routing remain disabled.

PC Framework 0.11.0-dev.1 and UI 0.3.0-dev.1 provide the current tested offline API combination. Stock checks, multiple CDs and invitation lifetime have server sandbox controls. Dedicated multiplayer NOT TESTED.
