B47ANCE'd Quartermaster helps you organize storage, put supplies away and keep track of what you need.

Tell each container what belongs inside, then sort your inventory, a room or an entire building from one menu.

[b]MP testing build - dedicated multiplayer NOT TESTED[/b]
Version 0.22.0-dev.1. Offline regression checks passed; native client and dedicated acceptance are pending. Back up saves and use matching builds on the server and every client.

[h2]Sorting made simple[/h2]
• Choose whole categories or individual items in a searchable tree with native item icons.
• Configure several containers in one window. Save keeps the editor open so you can select the next container. Give sections their own rules or share settings across a Whole Container.
• Save and reuse sorting presets, copy settings between containers and set destination priorities.
• Sort your carried inventory, a selected container, the current room or the entire building. Room and building sorting include your carried bags.
• Sort supported floor, Proximity Inventory, selected vehicle/trailer cargo and nested carried-bag sources into configured storage. Native access and capacity checks still apply.
• Find what you need with category/item search, Only Checked, Only Contents and optional grouping by mod.
• Make quick changes with Shift-click ranges, Ctrl-click, Select All Visible, Clear All Visible and Invert Visible.

Open Quartermaster from your player inventory. Select categories to include them, expand them to choose individual items, then save your container's rules.

[h2]Shopping lists[/h2]
Create a named shopping paper from one blank sheet using a retained notebook and pen or pencil. Choose among the lists you carry, give them to friends before a loot run, or hold one in either hand for a small paper checklist HUD. Writing supplies are needed for creating/editing; reading and collecting do not need them. Previous personal plans are preserved for explicit one-time import.
• Add items manually or from supported crafting, building and cooking recipes.
• Set quantities and see what you carry and what is still missing.
• Collect remaining items from eligible nearby storage.
• Choose acceptable condition, food state and remaining uses, with preferences for individual items.

[h2]Dibs! Wanted & Needed[/h2]
Give supplies a purpose and keep your goals together.
• Add personal Dibs! labels to items.
• Keep separate Wanted and Needed lists with target quantities.
• Track the supplies you carry, add missing amounts to Shopping and collect what remains.

[h2]Building Supply Ledger[/h2]
Sort now uses a carried Supply Sheet and pen/pencil by default. It first searches accessible loaded building storage for a completed covering ledger and picks it up through normal transfer; otherwise it uses a carried blank or unfinished sheet. After the entire successful Sort, one writing action updates confirmed touched storage. Blank sheets stay partial and unvisited entries keep their inspection times. Disable SortUpdatesLedger to restore the previous Sort workflow. Shopping collection still requires fresh completed location knowledge: carry a current completed paper supply ledger covering the location, or use a matching ledger CD loaded at an authorized powered computer in the building or nearby. A shopping paper does not replace the supply ledger. Shopping planning/reading and container configuration do not require a supply ledger; physical-list edits still need writing supplies. Server settings can disable either ledger requirement.
Computers open a Windows '93 desktop. Find a Quartermaster Application CD, load it through CD-ROM (D:) and run SETUP.EXE to install the app on each PC. The setup disc is reusable and need not stay nearby afterward. Use CD Writer to create a ledger CD, then load that disc and run QUARTERMASTER.EXE to view it.
Craft a Supply Sheet by consuming one whole notebook while retaining the clipboard and pen/pencil, then walk through building or safehouse storage to record what is there, including unconfigured containers. Paper pages show rooms, containers, quantities, locations and recording times. Interrupted inspections keep completed entries.

At a supported powered desktop computer, copy a completed sheet onto a chosen vanilla CD. The paper stays intact; the CD's original music is overwritten. Read the portable ledger CD at a supported powered desktop to search item names/IDs and browse rooms. Choose periodic live statistics, Disabled, no-expiry live statistics, or historical snapshots. The update interval defaults to 7 in-game days; computers can require manual inspection/CD updates or refresh automatically while powered in the exact building recorded by the loaded ledger. Off-site and safehouse-wide CDs remain readable snapshots under ordinary expiry. Live readers show confirmed contents of recorded storage; older snapshots and CDs are retained. The initial terminal is the stock desktop computer.

[h2]Rooms and your base[/h2]
Use [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3820077442]B47ANCE'd Rooms[/url] to designate rooms and organize storage around your base. Open Designate Room from Quartermaster, then choose room or building sorting when putting supplies away.

Quartermaster checks container and room access when sorting. Room policies apply to supported mod actions; they do not lock ordinary game interactions.

For automated cleaning, add the separate [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3820151540]B47ANCE'd Auto Clean[/url] mod.

[h2]Make it yours[/h2]
Resize the window, adjust the container divider and set background transparency. Mouse, keyboard and controller controls are included. Server sandbox settings control discovery range, area sorting, ledger requirements, physical lists, writing supplies and carrying allowance. Dangerous Load is optional and disabled by default; native capacity limits and encumbrance still apply.

[h2]Compatibility[/h2]
• Project Zomboid Build 42.21.
• Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3820077442]B47ANCE'd Rooms[/url] and [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3822042011]B47ANCED PC Framework[/url]. Enable both on the server and every client.
• Supports Better Sorting, Better Containers or [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3650035249]Extended Categories[/url]. Client-local category selections save explicit item choices. Reselect after changing category membership; follow each category mod's compatibility rules. Without category mods, Quartermaster uses vanilla categories.
• Optional shopping-list controls for Project Cook, Neat Crafting and Neat Building. Supported recipes only; shopping does not automatically craft, build or cook.
• Disable original Quartermaster and older B47 sorting copies.
• In multiplayer, use matching mod versions on the server and all clients.

[h2]Current limits[/h2]
Native client/dedicated acceptance is pending. The stock desktop uses a real CD in accessible adjacent storage. Live statistics cover recorded, loaded compartments; new storage requires inspection. Expired pages remain readable history. Selected vehicle/trailer sources are supported; automatic parked-vehicle area sweeps, vehicle destination designations, fluid tanks and unverified virtual storage are not. Cooking plans support full portions; partial portions and fluids are unsupported. Room policies do not lock unrelated vanilla transfers.

Room organization uses designated B47ANCEDRooms rooms only; native buildings define building scope. Allocation limits and live role routing remain disabled.

Source-only next iteration requires B47ANCEDUI API 1 in addition to Rooms and PC Framework. UI has no assigned Workshop item; no new upload is claimed. Dedicated multiplayer NOT TESTED.
