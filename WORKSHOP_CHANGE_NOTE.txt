[b]Version 0.13.0-dev.1[/b]
MP testing build - dedicated multiplayer NOT TESTED

Adds optional Extended Categories (CAExtendedCategories) support. Category choices save explicit item selections to handle different category detail settings across peers. Reselect after category membership changes and follow the category mod's own compatibility rules. No external classifier is bundled.

Adds optional Dangerous Load to Sorting load settings. Disabled by default. When enabled, Sort and Collect use your chosen 50–100% of the native inventory capacity, with server-validated saved preferences. Normal mode retains the existing comfort allowance. Native capacity restrictions, penalties, smaller transfer groups and action timing remain unchanged.

Includes the earlier overall progress, full-carry and selected vehicle/nested source work. Movement protocol 9 still requires matching server/client builds and reconnect. The load settings use a new capability family 1. Existing selections, presets and priorities are preserved.

Building Supply Ledger is an isolated prototype, not an available gameplay feature. No ledger items or CD conversion are activated. Native action authorization and item conversion still require verified bindings and testing. The shelf appearance experiment was removed from scope. Load-aware route timing has not been calibrated.

Offline tests only. Native SP/G6, dedicated multiplayer/G7 and stable release/G8 remain blocked. B47ANCE'd Rooms is required. This source note does not claim deployment or an upload.
