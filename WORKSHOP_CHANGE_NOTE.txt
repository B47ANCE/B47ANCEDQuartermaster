Find a Quartermaster Application CD, load it beside a powered PC and run SETUP.EXE. Install Quartermaster on that PC before reading ledger CDs, writing paper ledgers to CD or using its automatic ledger knowledge. The Application CD stays reusable in storage. Eject it after installation.

Installation uses PC Framework CD program API 1 and a server-validated native timed action. Existing ledger items/snapshots remain intact; existing PCs start uninstalled by default. Server settings control the requirement, install time and new-loot weight. Paper workflows and inventory/container Sort are unchanged.

Source-only development with paired PC Framework 0.5.0-dev.2. Offline regression and source checks pass; native SP/dedicated acceptance remain pending. No package, deployment or Workshop upload.
